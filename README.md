# MNIST Digit Recognition

A Machine Learning project that recognizes and classifies handwritten digits (0–9) using the MNIST dataset. The model was trained on 28×28 grayscale digit images and achieved **96.29% accuracy** using a Random Forest Classifier.

## Dataset
- MNIST Handwritten Digits Dataset
- 42,000 images
- 28×28 grayscale images
- 10 classes (Digits 0–9)

##Dataset Link:
https://www.kaggle.com/competitions/digit-recognizer/data

## Project Workflow
- Data Loading & Inspection
- Exploratory Data Analysis (EDA)
- Data Preprocessing
- Pixel Normalization
- Train-Test Split
- Random Forest Training
- Model Evaluation
- Model Saving with Pickle

## Results
- Accuracy: **96.29%**
- Algorithm: Random Forest Classifier
- Training Split: 80%
- Testing Split: 20%
